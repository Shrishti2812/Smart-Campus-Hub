# Smart Campus Hub

A modern campus dashboard that brings essential student services into one place.

## Features

### 📊 Attendance
- Track attendance status
- View attendance information easily

### 🎓 Grades
- Check academic performance
- View marks and progress

### 📚 Library
- Manage library resources
- Access book-related information

### 🍴 Canteen
- Explore canteen services
- View food availability

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- React Icons

## Project Purpose

Smart Campus Hub aims to simplify student life by providing a centralized platform for accessing important campus services.

## Future Improvements

- User authentication
- Real-time campus data
- Notifications
- Advanced dashboards
